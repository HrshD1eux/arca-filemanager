Privacy Policy

Effective Date: November 2026 • Last Updated: November 4, 2026

1. Overview & Commitment to Zero Telemetry

ARCA File Manager ("ARCA", "we", "us", or "our"), created by developer Harsh Pahal (hrshd1eux Studio), is built from the ground up as an offline-first utility. We believe that file managers should manage files—not monitor users.

ARCA does not collect, record, track, transmit, monetize, or sell your personal information, files, metadata, device identifiers, or usage activity.

2. Data Collection & Analytics

We do not integrate any third-party tracking, profiling, or analytics SDKs. Specifically:

  • No Analytics SDKs: No Google Firebase Analytics, Mixpanel, Segment, AppsFlyer, or Flurry.
  • No Crash Reporting Telemetry: No automated background crash log uploads (e.g. Firebase Crashlytics, Sentry). Crashes remain in your device's local Android logcat.
  • No Advertising Networks: Zero ads, banner networks, or behavioral targeting scripts.
  • No Cloud Accounts: No user registration, email logins, passwords, or cloud database storage.

3. Device Permissions Explained

In order to function as a full-featured Android file manager, ARCA requests standard platform permissions:

  • All Files Access (MANAGE_EXTERNAL_STORAGE): Required to browse, organize, move, copy, rename, extract, and delete files across your device's internal storage and attached SD cards / USB OTG drives. All file processing occurs 100% locally on your device's CPU and storage.
  • Internet Permission (INTERNET): Used exclusively when you explicitly initiate remote network connections (such as connecting to an SFTP, FTP, SMB, or WebDAV server, hosting the local Wi-Fi Transfer server, or tapping 'Check for Updates'). ARCA never opens sockets or background connections on its own.
  • Biometric / Fingerprint (USE_BIOMETRIC): Used locally on your device to unlock the Encrypted Vault if you choose biometric authentication. Cryptographic keys are managed by Android Keystore and never leave your hardware.
  • Foreground Service (FOREGROUND_SERVICE): Used to keep long-running user-initiated tasks active without OS interruption (e.g., compressing large archives, transferring large batches of files, or hosting the local FTP server).

4. Remote Network Storage Isolation

When you use ARCA to connect to remote servers (SFTP, SMB, FTP, WebDAV):

  • All network traffic travels directly and exclusively between your Android device and the destination IP address or host you specify.
  • There are no intermediate proxy servers, relay nodes, or third-party gateways.
  • Server credentials (passwords, usernames, private keys) are encrypted locally using Android EncryptedSharedPreferences and are never transmitted to any third party.

5. In-App Updates

When you tap "Check for Updates" in Settings or About, ARCA queries the public GitHub Releases API (api.github.com/repos/HrshD1eux/arca-filemanager/releases) to check if a newer release tag exists. No device identifiers, IMEI, IP logs, or personal details are included in this query.
