Philosophy & Mission

About ARCA File Manager

Your Files. Your Device. Zero Compromises.

Most pre-installed mobile file managers have morphed into ad-supported bloatware packed with intrusive cleaners, background telemetry daemons, push notifications, and forced cloud storage subscriptions.

ARCA was built from scratch to restore file management to what it should be: a pure, deterministic, and lightning-fast offline utility. ARCA treats your device storage with respect. No user telemetry, no analytics SDKs, no ads, and no external account requirements. Everything runs natively on your hardware.

⚡ Pure Offline-First

Internet permission is strictly reserved for your self-hosted remote connections (SFTP/FTP/SMB) and manual GitHub update checks.

🔓 Transparent GPLv3

Every single line of code is open source and auditable. No hidden trackers, no proprietary analytics, and no locked features.

🎯 Zero Gimmicks

No fake "memory boosters" or destructive cleanups. Clear, honest storage analytics backed by byte-exact filesystem scans.

All Capabilities

Detailed Features

Engineered for everyday utility, media management, power users, and deep filesystem workflows.

📦

Multi-Format Archive Hub

Full-featured compression and decompression engine. Create and extract 7z, ZIP, TAR, GZ, BZ2, and XZ. Supports password-protected RAR extraction with instant password verification and retry. Browse inside archives without extracting.

7z ZIP RAR TAR.GZ Password Protected
🔐

Hardware-Backed Encrypted Vault

Store sensitive documents, photos, and files in an isolated encrypted vault. Protected with hardware-backed AES-256-GCM authenticated encryption through the Android KeyStore HSM. Unlocks via Biometric (Fingerprint/Face) or master PIN.

AES-256-GCM Android KeyStore Biometric Unlock Zero Plaintext Cache
🌐

Transfer to PC & Local FTP

Built-in high-speed FTP server allowing your PC, Mac, or Linux machine to access, copy, modify, download, and upload files over your local Wi-Fi or mobile hotspot. Zero USB cables and zero internet connection required.

Full Read & Write Wi-Fi / Hotspot No Cables RFC 959 Standard
☁️

Remote Network Storage Suite

Connect seamlessly to your home NAS, cloud servers, or office networks. Full client support for encrypted SFTP, FTPS, Windows Network Shares (SMB 2/3), and WebDAV protocols with encrypted credentials storage.

SFTP SMB 2/3 FTPS WebDAV
📊

Dual-Engine Storage Analyzer

Visual storage breakdown across categories (Media, Docs, APKs, Archives). Discover large files, find exact byte-for-byte duplicates via SHA-256 hash matching, and safely clean empty folders with full path and properties inspection.

Large Files SHA-256 Duplicates Empty Folders App Analyzer
⚡

Batch Rename & Staged Queue

Multi-select actions let you inspect aggregate properties (size, item count, paths), batch rename multiple files sequentially with customizable prefix, suffix, and index numbers, and stage copy/move operations cleanly.

Sequential Batch Rename Multi-Select Properties Staged Transfers Trash Bin
🎨

Obsidian Design & Fluid Physics

Crafted exclusively in Jetpack Compose with Material 3. Features a true Obsidian OLED dark theme, subtle 0.5dp hairline containers, two-tone iconography, and hardware-accelerated spring scale-bounce micro-interactions on every tap.

Obsidian OLED (#0B0E14) RenderNode Spring Material 3 120Hz Fluidity
🎬

Integrated Media & APK Tools

Direct "Play", "Open With", and viewer actions for audio, video, and documents. Inspect APK metadata, permissions, package version, and target SDK directly before installing with security warning disclosures.

Media Dispatcher APK Package Inspector Image Preview Checksum Verifier
🔄

Direct GitHub Release Updater

Check for app updates directly against GitHub Releases without Google Play Services. Resumable background downloads via Android DownloadManager with SHA-256 verification and seamless PackageInstaller prompts.

GitHub Releases Resumable Downloads SHA-256 Verified Google-Free
Engineering Blueprint

Technical Architecture

Built with Clean Architecture, Kotlin 2.0+, and modern Android reactive patterns.

UI Layer

Presentation & Interaction

  • Pure Jetpack Compose: Declarative UI without XML or WebViews
  • Material 3 Design System: Adaptive tonal palettes and components
  • Type-Safe Navigation: Kotlin Serialization-backed route management
  • Spring Physics: Hardware GPU RenderNode scale micro-interactions
Domain Layer

State & Use Cases

  • Unidirectional Data Flow: StateFlow and SharedFlow reactivity
  • Kotlin Coroutines: Structured concurrency and background task dispatch
  • Zero Background Drain: Active operations run only on explicit user intent
  • Strict Encapsulation: Decoupled repository and use case boundaries
Engine Layer

Storage & Network

  • Unified StorageNode: Common model for local, OTG, and remote files
  • ArcaFtpServer: Low-overhead RFC 959 bidirectional socket engine
  • Multi-Archive Hub: Native Apache Commons Compress & UnRAR
  • Network Protocols: High-performance JSch, SMBJ, and WebDAV
Security Layer

Cryptographic Integrity

  • Android KeyStore: Hardware-backed HSM key generation and storage
  • AES-256-GCM: Authenticated symmetric cipher with zero plaintext swap
  • BiometricPrompt API: Strong biometric face & fingerprint gating
  • Encrypted SharedPreferences: Secure encrypted remote credentials storage
