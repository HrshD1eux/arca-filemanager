File Manager for Android

Engineered for Power & Privacy

Everything you need in a modern Android utility without bloat, ads, or background trackers.

🛡️

Fully Offline & Private

Zero telemetry, zero analytics SDKs, and zero cloud accounts. All local file operations, compression, and encryption execute strictly on your device.

🎨

Tonal Depth & Micro-Interactions

True Obsidian OLED dark theme, subtle 0.5dp borders, two-tone iconography, and hardware-accelerated RenderNode scale-bounce tactile feedback.

📦

Multi-Archive Powerhouse

Full support for 7z, ZIP, TAR, GZ, BZ2, XZ, and password-protected RAR extraction with resumable background integrity testing.

🔐

Hardware-Backed Vault

Encrypt sensitive files and documents using authenticated AES-GCM encryption protected by biometrics or a custom secure PIN.

🌐

Network Storage & Wi-Fi PC Transfer

Seamless SFTP, SMB, FTP, FTPS, and WebDAV client integration, plus an embedded local FTP server to transfer files to any PC over Wi-Fi.

📊

Storage Analyzer & Cleanups

Visual storage breakdown, large file hunter, duplicate file discovery, and empty folder tidying with detailed properties inspection.

Technical Architecture & Transparency

ARCA is built strictly following modern Android development best practices:

  • Language: 100% Kotlin 2.0+ with Coroutines & StateFlow
  • UI Framework: Jetpack Compose with Material Design 3 guidelines
  • Storage Isolation: Android 11+ Scoped Storage & MediaStore architecture with transparent permissions
  • Licensing: Licensed under GNU General Public License v3.0 (GPLv3)
  • Network Transparency: Internet permission used exclusively for user-configured remote servers (SFTP/SMB/FTP/WebDAV) and manual GitHub release updates
