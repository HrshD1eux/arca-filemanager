User Data Deletion Policy

Complete User Sovereignty • Google Play Data Safety Compliance

1. Why There Is No Cloud Account to Delete

ARCA File Manager does not operate remote user databases, cloud accounts, or central backend servers. We never ask you to create an account, provide an email address, or log into our services.

Because zero user data is ever uploaded to or stored on our servers, there is no remote account or database record to request deletion of.

2. How to Delete All Local Application Data

You have complete control over the data stored locally on your device. You can purge all application preferences, bookmarks, encrypted vaults, and cached thumbnails at any time using standard Android system controls:

Option A: Clear App Storage (Instant Reset)

  1. Open your Android device's Settings app.
  2. Navigate to Apps or Application Manager.
  3. Select ARCA from the list of installed apps.
  4. Tap Storage & Cache.
  5. Tap Clear Storage (or Clear Data) and confirm.

Result: This immediately deletes all local app preferences, stored network configurations, saved folder shortcuts, recent history, and internal cryptographic vault keys stored within the app's private sandbox directory.

Option B: Uninstalling ARCA

Uninstalling ARCA completely removes the application package and automatically deletes its entire private data directory (/data/data/com.Hrshd1eux.filemanager) managed by Android OS.

3. Managing User Files & Encrypted Vault Items

Files that you create, download, or move onto your shared storage (such as in /sdcard/Download or /sdcard/Documents) remain on your physical storage device until you explicitly delete them using ARCA's delete/trash functions or your device's native file manager.

If you placed files inside ARCA's Encrypted Vault, you can permanently shred or delete them directly from the Vault screen before clearing app data or uninstalling.
